# SCUT 参考车 P3：无梁预训与标准梁验收

当前入口用 `config/reference/scut_p3.yaml`。这是参考车仿真实验配方，不适用于上大实车。旧混训 run 的数值不代表新任务成绩。

## 实心梁

依据《RoboMaster 2027 机甲大师超级对抗赛比赛规则手册 V1.0.0（20261015）》印刷页 59、§4.4.2 图 4-38：梁前沿距道路入口 1.350 m，沿行进方向长 350 mm，车道净宽 800 mm；道路表面高出场地基准 G 200 mm，梁顶高出**道路表面** 270 mm。把路面设为局部 `z=0`，用 `0.350 × 0.800 × 0.270 m` 的实心盒模拟车道内顶面投影；盒中心为 `(1.525, 0, 0.135) m`。不挖洞、不建护栏实体，不复现道路高度台差或裁判卡。MuJoCo 用 `python -m tools.build_tunnel_model` 生成同一尺寸的标准模型。

## 顺序

1. `p3-jump` 无梁。每回合固定为零速或正向行进，默认各 50%；每个训练回合都在 2–5 s 安排一次模拟按键，不再抽样完全不跳的训练回合；评测仍保留不按键对照。速度和机身上升目标是参考车试验范围，不是已验证能力。先分别确认原地和带速跳能离地、落稳，并从 `jump_motion.npz` 查看在足够净空下的**连续前进距离**，不能用起跳 `vx` 或单个峰值替代。
2. 用同一平地 checkpoint 直接评 `p3-tunnel`。所有用例有标准梁，按速度、早／晚按键分组，记录离地、通过、触地、落稳，不混入原地样本。位置用于仿真脚本模拟操作手按键，不是部署触发方案，不把测距交给 Actor。
3. 直接评测已有足够成功率和按键窗口就不另训。否则用 `--initialize-from` 仅继承平地 Actor 开新 `p3-tunnel` run，不能完整 resume 旧混训。顶面落地、碰撞、绕行、首轮过早触地均失败。30 mm 净空、50 mm 后沿裕量、1 s 落稳是训练验收约定；轮底和刚体原点只是近似，完整净空仍需按目标资产验证。表 5-27 的裁判卡窗口另测。

## 奖惩

借鉴复旦的支撑期蹬伸、华南虎的起跳／收腿分相：蹬伸以有轮支撑的向上速度为主，目标速度以上不额外发分；蹬伸和下降准备都用单边腿长引导，0.28 m 以下只按短缺折减，达到后再伸不减分，不追踪腿长随时间的轨迹。0.28 m 是参考车试验值，不是关节限位。无梁原地/带速跳取消固定 0.25 s 下蹲和下蹲奖；按键后即允许在有轮支撑且机身向上时获得蹬伸奖，策略可按状态自行决定是否预蹲、蹲多深、何时起跳。越梁不改。关闭按腾空时长发奖、空中奖金、轮速对齐罚和未经实际冲击测量的髋力矩代理罚。平地以确认离地后至首次触地前的 `max_t(min(左轮底净空, 右轮底净空))` 考核：低于目标减 0.01 m 时不计入升档，但落稳且带速合格（如适用）仍可拿按净空差距平滑折减的最终净空奖；达标和超高都给满 +2。稠密净空进展奖和带速门槛不变；落稳奖为 +2。机身上升量只做诊断。评测另报 `jump_overshot`（确认离地且超目标 0.03 m）和 `jump_height_in_band`（达标且未超高），避免把跳得更高和精确控高混作同一个指标。过梁不按机身升高量判失败或发顶点奖。空中速度跟踪降权，触地后恢复跟踪，落稳和速度恢复分开看；碰梁沿用一次事件失败罚，不再叠加顶面持续罚。

**无梁跳跃计时**：按键后 1.2 s 内须确认离地；确认后不设单独的滞空时限，仍受训练回合、评测时长与安全终止约束。首次有效触地后 5.0 s 内必须完成双轮连续落稳 1.0 s（这 1.0 s 包含在 5.0 s 里）。任一轮离地、姿态不合格、`|vz| ≥ 0.20 m/s` 或横滚/俯仰任一角速度绝对值 `≥ 1.0 rad/s` 都清零连续落稳计时，后续触地不延长截止时间；提前落稳就立即结算。跳跃事件期间，配置内的机身触地一旦超过现有接触力阈值就直接判失败，不等普通摔倒计时，沿用一次 −4 的事件失败罚。落地恢复阶段以 −0.8 的权重连续惩罚支撑不足、角度/角速度/垂直速度偏大和前速偏离指令；带速不是急刹。单独的 `jump_touchdown_tilt` 只在首个轮触地的策略步记一次，按横滚/俯仰角平方和相对 0.25 rad 归一化扣分，最多 −1，不惩罚飞行或之后的恢复过程。另轻罚首触前一帧明显过快的向下速度，只罚一次并封顶；首触后双轮无支撑的大幅向上反弹也连续扣分，小反弹仍可恢复。阈值和权重是仿真试验起值。Actor 的阶段时钟仍按 1.2 s 缩放，越梁流程及硬失败判据不变。新配方不改变已启动的训练；切换时新开 run、只继承 Actor。

**防空中抽腿（无梁）**：原有收腿与落地伸腿根据随腿长变化的轮底距离逐帧切换。现在确认离地后先收腿，过顶点且机身垂直速度首次达到 −0.25 m/s 或更低时直接切到落地伸腿，不再等估计触地倒计时、也不回切；首触结束伸腿引导，反弹不重新开。收腿用较长一侧计分，0.28 m 时无分、0.15 m 收够即满，之间平滑给分；另只在首触前的腾空中惩罚腿部动作二阶差分，不惩罚维持一个伸缩速率，不恢复固定腿长轨迹。评测 `jump_motion.npz` 记录左右腿长、原始腿动作、收/伸掩码和触地状态；用同检查点/同工况比较腿动作和实际腿长，区分策略输出抖和跟踪抖。

## 分组跳高课程与稠密引导

- **共享 Actor，课程独立**：用每回合固定的速度目标分原地／带速，不按瞬时速度重新分组。各组独立维护八档采样、当前最高档的窗口及每档引导退火，并各自保存在 checkpoint。双轮净空目标暂沿用 4、9.25、14.5、19.75、25、30、35、40 cm（初始档位、待实测校准，不能换算为旧机身上升档位）；仅解锁第一档时只采第一档，之后 60% 采当前最高档，40% 在已开放的低档间均分。40 cm 是仿真课程目标，不是已验证跳高能力。窗口达到至少 500 次已触发的已结算尝试时判定一次（同一批新样本一并计入）；达到 70% 就升一档，否则留在原档。无论是否通过都开始新窗口，不累计前窗失败。已开放的低档仍混采，但不计入升档。带速跳在确认离地时还要达到目标前向速度的 70%，否则仍可获落稳奖，但不给跳高达成奖、不视为该档成功。按键前失败不进训练升档窗口；独立评测的未按键对照不算跳跃尝试。TensorBoard 分别查看 `Jump/stationary/*` 和 `Jump/moving/*`：`window_count` 是当前窗口样本数，`levelN/last_window_success_rate` 是该档上一次已结算窗口的成功率（尚未结算则为 0）。旧累计课程或旧奖励配方的 checkpoint 用 `--initialize-from` 迁移 Actor，不沿用旧课程成功计数。
- **不是全稀疏，稀疏的是结果反馈**：下蹲、蹬伸、收腿、准备本来就逐拍计分，但最终顶点奖和落稳奖要等触地并落稳 1 s 才结算。只在无梁阶段增加 `jump_height_progress`，确认离地后对本次首次触地前新达到的归一化双轮净空按增量发奖，最高到目标高度；一次跳最多 +0.5，独立按本组本档的引导系数退火。保持高度、下降后再次爬到已付高度、超高、无有效离地都不加分。越梁阶段不使用该项，也不恢复按腾空时长付费。SCUT 无梁的蹬伸、收腿和下降伸腿不退火。蹬伸参考为固定向上速度 2.0 m/s（非起跳阈值），不把轮底净空代入弹道机身速度公式。
- **下一轮观察**：与 `jump_height_progress=0` 对照，固定初始 Actor、配方其余项和种子；按原地／带速看确认离地率、带速合格率、跳高达标率和落稳率。若只涨离地、落稳反而掉，先减小进展权重，不继续加腾空奖励。这里的 0.5 和 70% 是参考车实验起值，尚未用 PPO 结果验证。

**响应时间**：目前只有按键后 1.2 s 内确认离地的超时约束，没有独立的抢跳奖金。固定工况评测分别对所有确认离地样本与最终成功样本输出按键至确认离地的 P50/P90（包含 30 ms 确认期）；连同离地率、净空达标率、落稳率及带速合格率一起比较，不能靠只留下快但少的成功样本得出改善。

## 运行入口

使用准备好的 SCUT `robot.yaml`；下列 `<...>` 替换为已有文件。先完成基线验证或按现有流程显式记录基线覆盖。

```text
python -m isaac.scripts.train --task p3-jump --robot <robot.yaml> --policy config/reference/scut_p3.yaml --run-name p3_flat --initialize-from <landing.pt> --headless
python -m isaac.scripts.evaluate --task p3-tunnel --robot <robot.yaml> --policy config/reference/scut_p3.yaml --checkpoint <p3_flat.pt> --output runs/p3_beam_eval --headless
python -m isaac.scripts.train --task p3-tunnel --robot <robot.yaml> --policy config/reference/scut_p3.yaml --run-name p3_beam --initialize-from <p3_flat.pt> --headless
```
