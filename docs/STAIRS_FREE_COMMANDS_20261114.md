# stairs自由转向调整

本页为revision 7，优先于revision 6中“非平地只有小转向、仍有+x奖励/卡住惩罚”的历史说明。

## 仅井字和粗糙地形的自由指令

- grid/rough使用command_mode=free；flat保持原motion，所有上下台阶及slope保持traverse。
  一个Actor、一个连续回合，不分机动/穿越训练。奖励依然按地形kind分区，不让grid/rough误用平地权重。
- 安全出生平台先保持原前进/倒退方向进入实际障碍区域；两轮进入surface后立即重采样。
  后续站立/直行/纯自转/组合概率15%/35%/20%/30%，每3–7秒采样，现有指令slew保留。
  直行/组合正反方向各半；速度范围沿用各自逐行速度课程。转速限幅随同一速度课程从0.5增到2rad/s，
  初始fraction=0.4对应约0.714rad/s；这不是给台阶/坡道扩大转速。
- free关闭航向保持覆盖、终点停车和越过后立即结束；正反运动的扫描方向跟随实际非零vx指令。
  仍受地块边界中性截断和真实物理失败约束；不允许跨进相邻地形混记数据。
- 课程只累计实际surface内且非飞行/缓冲的跟踪样本，至少3秒，结束时仍在surface并恢复支撑才可成功。
  无须为了纯自转到达+x终点。初始化接近平台站稳不算掌握井字/粗糙；未进入地形就一直停住不能成功升级。
- free课程评分单独采用exp(-(error/(0.1+0.25*abs(command)))^2)，分别用于vx与wz；
  原tracking_promote=0.6门槛保留。奖励函数不因此改变，台阶/坡道原课程评分不变。
  原0.25m/s指令下完全停住的速度评分约0.882，新free课程评分约0.094，避免仅存活就升级。
- critic添加free标志和surface有效时间两个状态，共375维；Actor仍35维，obs_version=2，合同revision=7。
  旧checkpoint用--initialize-from，不能--resume。

## 卡住与副作用检查

- 删除方向奖励不等于绝无停留局部最优：在高度门控=1时，0.25/0.4/0.5m/s指令下停住，
  速度跟踪奖励加误差惩罚分别仍为约+0.851/+0.646/+0.482每秒，而精确跟踪是+1。
  因而只是运动有收益优势，不能保证这点优势始终覆盖运动代价；宽核减半缓解常数收益但不能保证消除卡住。
- 保留的高度门控会在高度偏差>=0.1m时同时关闭速度奖励与误差项，这仍可能让尚未站好的机器人优先修高度。
  本轮不改高度门控和其他奖励权重。
- 新增分地形actual_abs_vx、velocity_error_abs、yaw_error_abs、moving_command_ratio、
  commanded_but_stationary_ratio和surface_active_seconds。最后一个比率的分母为全回合时间，
  排除主动站立/纯自转以及飞行/缓冲，不等同于所有移动样本的条件卡住率。
- 自由运动可在surface外继续收到合法指令，但这段不计入地形课程；正常出界被排除，
  因而仍必须联合查看neutral_exit_rate和eligible_episodes，不能仅凭条件成功率判断效果。
- 课程速度与转速上限当前联动，成功依据整回合平均跟踪，并非四种指令逐项验收；
  单个回合可能偏重站立/自转，因此仍不能把升到最高行理解为四类动作均已掌握。
- 原固定命令评测仍以已有直行穿越案例为主，本轮未增加“进入障碍后固定自转”的评测编排；
  不能用其既有通过率声称纯自转已验收。MuJoCo手动转向可观察行为，但本轮未执行。
- stairs平地课程与高站姿联合采样仍未实现，此任务没有授权扩大到该项。

## 宽核高度奖励

仅stairs的track_height_wide从继承的2.0改为1.0（减半），所有stairs地形生效。
紧核高度奖励、高度误差扣分、高度门控和最高高度范围不变；独立flat的退火方案、landing/recovery不改。
1.0是本轮温和减少驻留正收益的设计权重，不是已经验证的最优值。

## 方向无关的运动目标

stairs删除世界+x进展奖励和按+x位移判断的卡住惩罚，配置项一并删除。
现有航向系速度跟踪、转速跟踪、站立漂移、姿态/接触和动作平滑项继续生效。
倒车、转弯、自转不再因为世界+x位移不足而受罚；不是取消所有不运动的代价，
非零速度指令下停住仍损失跟踪奖励并产生跟踪误差惩罚。
recovery自身进展/卡住规则不改。旧TensorBoard的progress/stuck曲线不能和新总回报直接比较。
本轮仅静态检查及配置加载；未运行测试、Isaac/GPU或MuJoCo，未推送或更新云端训练。
