# 键鼠驾驶台阶策略

入口 `tools/play_stairs.py` / `tools/play_stairs.ps1`。复用相邻 `../sim2sim/sim2sim.py` 的
Actor、闭链/弹簧、PD、摩擦中值与观测/动作延迟；不改旧 `play.py` 和 landing 播放器。
需要该sim2sim目录、`runs/scut_experience/scene.xml`及它引用的网格资产；本机使用mjlab Python环境。
源码在本训练仓库，场景、快照、日志均在`runs/stairs_viewer/`，不修改两校参考仓库。

运行（仓库根目录）：

```powershell
D:/Anaconda3/envs/mjlab/python.exe -m tools.play_stairs
# 或从任意目录调用：
./tools/play_stairs.ps1 -Python D:/Anaconda3/envs/mjlab/python.exe
# 其他同任务快照：
python -m tools.play_stairs --run runs/<下载目录> --profile down_two --row 3
# 无小键盘：显式启用独立面板字母键，必须先点击该面板，不能在MuJoCo窗口按WASD驾驶
python -m tools.play_stairs --panel
```

默认读取`runs/stairs_viewer/checkpoint/`，目录内须有`model_<轮数>.pt`和匹配的
`params/robot.yaml`、`params/policy_meta.yaml`、`params/run.json`。选择其中轮数最高的模型；
脚本不连接云端、不热替换运行中的模型。下一次下载新检查点到该目录并重启即可加载。
仅接受p1-stairs、单帧obs_version=2、35→6的Actor。

地图包含训练配置的11种地形、每种8行，共88块：平地、单/双上台阶、单/双下台阶、
单/双上下混合、快速混合、井字小突起、坡道和随机起伏。几何尺寸从该run的policy快照读取。
难度使用每行区间的中点，非Isaac的逐块随机难度；井字交叉处分割，宽高间距采用相同随机化。
坡/起伏使用MuJoCo高度场，采样网格与训练相同，三角剖分与接触求解器不保证一致。
各类型等量铺设用于手动选择，不代表训练采样比例；地块之间留间隔，下面有兜底地面。

默认沿用原sim2sim的小键盘驾驶；独立面板默认用鼠标，不启用字母驾驶键。
控制面板选择地形、难度行和正向/倒车出生，点击“到所选地形出生点”。
初始为单级上台阶第2行（单级约6.125cm），速度为0，不会自行冲向台阶。
默认站姿沿用sim2sim默认关节姿态；下台阶按平台高度出生，不从地面穿进平台。

| 可选`--panel`面板键盘/鼠标按钮 | MuJoCo窗口小键盘 | 功能 |
|---|---|---|
| W / S | 8 / 2 | 速度指令±0.25m/s，与旧sim2sim相同 |
| A / D | 4 / 6 | 转向指令±0.5rad/s，与旧sim2sim相同 |
| R / F | 9 / 3 | 高度±0.02m |
| Space | 5 | 速度/转向目标归零，按原斜率停车 |
| 1 / 3 / 出生按钮 | 0 / 小数点 | 在所选地形入口重置 |
| 倒车复选框+出生按钮 | Enter / * | 切换车头朝向，倒车用负vx沿路线前进 |
| 地形下拉框+出生按钮 | + / − | 切换地形 |
| P | / | 暂停/继续 |
| Z | 7 | 正常、0.5、0.25、0.1倍速 |
| C | 1 | 跟随/自由相机 |

W/S等字母键仅在显式`--panel`且控制面板获得焦点时生效；MuJoCo窗口只用小键盘（NumLock开启），
不能用顶排数字代替。面板按键在Tk默认控件绑定之前处理，避免Space同时触发按钮与停车。
这些是累加指令，松键不会自动停车，小键盘5停车。鼠标可点击面板按钮、旋转/平移相机、滚轮缩放；
MuJoCo窗口双击刚体选择，再Ctrl+右键拖动施力。失败后冻结供观察，需要重新出生。
本工具自由驾驶，不自动转向、不自动沿训练路线停车，也不把驶离路线计为完成；HUD显示路线位置，
不宣称给出正式训练通过率。手动转向超过训练±0.1rad/s时HUD提示分布外指令。

Actor模式位由真实地形射线构造：复用`wheelleg.stairs.scan_course`，273点、轮轨升降沿、
台阶提示保持与接近上沿抬高逻辑均来自训练配置；不会直接把完整扫描给Actor。
地面高度/离地高度根据轮下地面计算，避免上平台后把平台高度当作机器人腾空高度。
界面显示当前速度、高度、roll/pitch、双轮接触力、台阶提示、原始动作最大值。

**模型限制：现有sim2sim的MJCF没有训练USD中的16个独立导轮刚体。**
脚本明确报告缺失，导轮力显示N/A，保留存在的机身/连杆接触诊断；没有伪造导轮或将导轮力当0验收。
因此可检查Actor在相似地形上的基本响应，但不能用它验证导轮承重收腿、导轮冲击或与Isaac等价的通过率。
精确导轮碰撞和完整资产转换需要另外补齐。MuJoCo摩擦仍是训练范围中值的近似，不代表两引擎完全等效。

`--build-only`只编译场景、构造出生观测并运行一次Actor，不启动窗口、不推进物理。
本次做必要模型加载和射线读数检查，不运行pytest或Isaac/GPU训练，不修改云端训练。

## MuJoCo自带快捷键与地图显示修复

按本机MuJoCo 3.11.0的simulate源码帮助表及`mjVISSTRING`/`mjRNDSTRING`核对。
我们的机器人控制回调不处理这些键。原地图在group3，MuJoCo默认仅显示0/1/2组；
现启动时显式显示group3和静态物体，面板“恢复地图显示”可重新打开两者。

| MuJoCo窗口原生操作 | 作用 |
|---|---|
| 顶排0–5 | 对应几何分组显示/隐藏；本地图为3，机器人碰撞/外观分别为1/2 |
| D | 显示/隐藏静态物体，包括地形；不要把它当右转 |
| W / S / R | 线框 / 阴影 / 反射；不是前进/后退/抬高 |
| C / F | 接触点 / 接触力可视化 |
| T / X / J / M | 透明 / 纹理 / 关节 / 质心可视化 |
| F1 / F2 / F3 / F4 / F5 | 帮助 / 信息 / Profiler / 传感器 / 全屏 |
| F6 / F7 | 循环坐标系 / 标签显示 |
| Tab / Shift+Tab | 左侧 / 右侧原生设置面板 |
| Esc | 自由相机；脚本不再每帧强制覆盖回跟随模式 |
| [ / ] | 切换模型中的固定相机（没有固定相机时无变化） |
| 左键拖动 / 右键拖动 | 旋转相机 / 平移相机，Shift改变移动方向 |
| 滚轮 / 中键拖动 | 缩放 |
| 双击 / Page Up | 选择刚体 / 选择父刚体 |
| 右键双击 / Ctrl+右键双击 | 相机对准所点位置 / 跟踪所选刚体 |
| 选择刚体后Ctrl+拖动 | 旋转扰动；Ctrl+右键拖动为平移扰动；Shift切换方向 |

原生独立simulate中的Space暂停、左右箭头步进/回溯、主键盘+/−调速，
在`launch_passive`外部Python驱动模式下不接管本脚本的物理循环。
本工具暂停用小键盘`/`，慢放用小键盘7，停车用小键盘5；不要依赖原生Space暂停。
