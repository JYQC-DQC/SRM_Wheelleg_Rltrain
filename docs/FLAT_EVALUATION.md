# Flat 选模和后续训练对照（2026-11-12）

## 选模协议

目的：同一份配置、同一组种子和初态比较确定性 Actor，不根据随机训练回报挑模型。
脚本只评测，不改 checkpoint，不恢复优化器，不改变训练任务或奖励。

- `isaac/scripts/evaluate.py`：p1-flat 默认精细协议；其他任务不变；`--suite legacy` 保留旧协议。
- `--checkpoint` 接受多个文件，必须使用相同机器人、观测和动作合同。跨阶段 Actor 可回归 flat。
- `--evaluation-policy` 只覆盖 `training.evaluation`。旧 run 使用自己的 robot/policy 快照，不能把新模板的
  轮速上限、PD 等一起换掉。覆盖后的评测配置、机器人配置和所有用例写入输出，checkpoint 记录 SHA256。
- 输出目录必须不存在。完整评测较慢，首次调用建议只选一个 checkpoint；不自动运行训练或远端任务。

默认每个高度 34 个用例，三个高度加两条高度切换，共 104 个用例。只有 random_start 组跑全部种子（默认两个），
其余用例没有随机性，只跑第一个种子；每次 16 个环境，共 107 次、1712 条仿真轨迹/模型。
这不是 1712 条独立随机试验：除随机出生组外，同工况克隆环境可能重复，
不能用它们计算独立样本置信区间或宣称泛化成功率。

| 组 | 默认覆盖 |
|---|---|
| stand | 训练高度范围的低/中/高三档 |
| straight / turn | 训练正负上限的 25%、50%、100% |
| combined | 正负 vx × 正负 wz 的四象限；50%、100%；用组合转向上限 |
| dash | 训练冲刺正负上限 |
| transition | 前进刹停、倒车刹停、前后反向、正反转向 |
| height_transition | 静止和移动两种低→高→低 |
| random_start | 训练范围内随机左右腿长/摆角、机身倾角和朝向 |
| push | 稳定站立后机体系前后左右固定速度增量，默认 0.25 m/s；不是力脉冲 |
| delay | 默认物理步延迟 [3,3]、[8,5]，2 ms/步；分别明确记录 |

默认先给 2 s 起立窗口，每个目标保持 20 s。指令使用训练配置中的速度/转速/高度变化率，
Actor 在当前指令写入后推理。目标到位后等 2 s 才统计稳态；切换期间仍计失败、接触和全程误差。
环境超时由最长用例设置，不会在训练原有 20 s 上限自动重置后继续冒充同一条长轨迹。

随机出生使用已有训练出生实现，其他控制和物理随机化关闭。名义组使用 `evaluation.observation_delay_steps`
/ `action_delay_steps`，参考配置取训练随机范围中值（观测 5、动作 4 个物理步；训练从未见过零延迟）；
delay 组单独设置物理步数。旧 run 快照里的延迟仍是 0，需用 `--evaluation-policy` 传入新配置。**此协议没有测试随机摩擦、质量、传感噪声或持续力扰动，不能视为 sim2real 验收。**

## 指标与通过条件

每条轨迹的误差输出全程/稳态 MAE、RMS、P95、最大值；每个切换片段分别输出 MAE，任何片段不达标即该回合失败。
记录 roll/pitch、非轮接触占比和最长连续时间、轮接触力、六通道动作和关节速度、动作一阶差分、
名义力矩利用率，以及腿、轮分开的输出目标裁剪占比。动作幅度、动作差分和裁剪占比只统计起立窗口之后的帧。力矩是策略步末采样，不是 500 Hz 子步峰值；
名义限幅占比也不等于 SRM 速度相关 DC 包络饱和占比。

恢复时间：指令完成 slew 后（推扰组从推扰发生时刻起），误差/倾角/接触连续达标 0.5 s 的窗口起点。
未恢复写 null，并单独计数；不得当成 0 秒。默认要求不超过 3 s。初始 2 s 的动作保存在全程指标，
这不是从出生瞬间算的完整起立时间。

零指令漂移：进入稳态后固定 10 s 的最大 XY 位移；刹停后重新确定原点，推扰后单独测量。
不会把有指令直行的位移叫漂移，也不会纳入自动重置后的轨迹。

跟踪误差门槛与训练指令课程相同（`command_curriculum`，env.py `_reset_idx`）：速度、转速的平均误差须小于
`底限 + relative_error × 同一批样本的平均指令幅值`，高度平均误差须小于 `height_error_threshold_m`，均为严格小于。
整段稳态和每个切换片段各自按自己的样本计算；恢复判定逐帧使用当前指令对应的门槛。
参考配置：速度 0.1 + 0.25×|vx|，转速 0.1 + 0.25×|wz|，高度 0.05 m。其余工程门槛（policy YAML 可改；不是实测参数）：

| 指标 | 默认门槛 |
|---|---|
| 速度 / 转速 / 高度 MAE | 同训练课程，见上 |
| 稳态零速 10 s 最大漂移 | ≤0.2 m |
| 启动后绝对 roll/pitch 最大者的 P95 | ≤10° |
| 启动后非轮接触时间比例 | ≤1%（接触力阈值沿用配置） |
| 连续达标恢复时间 | ≤3 s，并保持 0.5 s |
| 回合 | 无物理/数值失败、没有提前 timeout、完成全部时长 |

失败当步使用重置前快照，之后的所有帧剔除；失败回合不能因为只留下短而简单的有效片段而被判通过。
报告保留全部分母、各回合通过与否、完成时长；没有有效样本写 null，而不是伪造零误差。

## 输出和选择

- `protocol.json` / `params/`：固定协议、种子、工况和实际使用配置。
- `ranking.json/md`：数值失败数→物理失败数→最差组通过率→各组通过率等权平均→稳态误差比。
  稳态误差比 = 稳态 MAE / 课程允许误差，按速度、转速、高度三项平均后再对回合、用例平均，越小越好；
  只统计有稳态样本的回合，失败回合已由前面的失败数排序。
- 每个模型的 `evaluation.json/md`：逐工况、逐种子、逐回合指标；排名第一不等于验收通过。
- `traces/*.npz`：指令、状态、有效掩码、事件、动作/力矩；默认每 5 个策略步存一帧，额外保留失败帧。
  所有统计先用完整 100 Hz 数据计算，再降采样保存；不要用降采样数据反算接触尖峰。
- `rollout.npz`：兼容导出的 Actor 观测样本（开启历史估计器时另存 `history`）。`transition_states.npz` 仅保存通过轨迹的末态，可能为空，不能伪造。
- `--video` 为每个用例/种子录制视频，默认不录以避免大量视频；画面不代表全部并行环境。

建议第一轮 5000/6000/末期三个模型，同协议评测；再围绕胜出模型比较相邻保存点。
以最差任务和失败数筛选，再比较轨迹中的抖动、漂移、瞬态和饱和；不为一个小数差异宣称显著优势。
最终用另一份 evaluation 配置换独立种子复核随机出生，并另作物理参数/噪声鲁棒性和 sim2sim 评测。

## 为什么暂不移植全部 SCUT 算法

当前 Actor 是单帧 35 维 MLP，上一动作不等于完整观测历史；critic 的真实速度和地形扫描只参与训练，
部署 Actor 不会因此直接得到这些信息。SCUT 有独立实验分支：

- DreamWaQ：历史编码器估计速度及潜变量，并做重构和 KL 等训练。见 SCUT
  `source/agent_rl/agent_rl/rsl_rl/modules/actor_critic_dreamwaq.py`、`algorithms/ppo_dreamwaq.py`。
- HIM：历史→显式速度估计+隐变量，速度监督和 prototype/swapped-assignment 学习。见 `modules/him_estimator.py:92-125`。
- NP3O/Barlow：约束成本通道和历史表示；不是 PPO 多加一个权重。V14 配置列出倾角、高度、角速度、
  力矩、关节速度约束，且不同的网络和观测组，见 `wheelbipe_V14/env_cfg.py:2002-2063`。

潜在收益是用时间信息区分打滑、接触变化和状态估计歧义；当前的转速通过率不足不能单凭曲线归因于缺历史。
代价包括新观测合同、历史缓冲复位、训练损失、ONNX 导出、固件输入和资源预算。
若固定评测显示持续零速漂移、打滑或随机参数下退化，再在同协议下 A/B，比直接换算法更有依据。

### 复旦采用的历史估计器

本地 `fudan_rl_wheel_leg/plane` 和 `jump` 的基础配置都是单帧25维、5帧历史，
encoder为125→128→64→3；Actor接收当前观测和编码结果。类名 `ActorCriticSequence`，
但 `is_recurrent=False`，是对历史向量做MLP编码，不是LSTM。
PPO实现另有encoder更新：前三维与critic中的真实机身线速度做MSE；latent>3时，
其余维度与对应的特权观测分量做去噪MSE。没有DreamWaQ的同一套VAE目标，也没有HIM的prototype目标。

来源：FD `plane/wheel_legged_gym/envs/base/legged_robot_config.py:35-43,274-308`；
`rsl_rl/modules/actor_critic_sequence.py:42-110,194-198`；`rsl_rl/algorithms/ppo.py:256-285`。
`plane/logs/wheel_legged/history10latent16_pd602.00.2terrian/legged_robot_config.py:41,289` 则是10帧/16维，
这是历史实验快照，不能从目录名证明性能优于默认版本。复旦默认sim.dt=0.005、decimation=2，对应100Hz策略。
如果本项目后续先尝试最小的显式速度估计器，复旦路径比迁入整套NP3O更直接；仍需独立评测判断收益。
2026-11-12 已按指南 §7.2 实现该估计器（5帧、速度MSE+接触BCE），默认关闭、尚未训练，用法见 `TRAINING.md`。
指南里“5维输出含两轮接触概率+BCE”是本项目拟议扩展，不是复旦当前代码的事实。

## 粗糙地形怎么移植

P1 已有 stairs/recovery 共用生成器和 77 点 critic 扫描：30% 平地、单台阶/双台阶各20%、坡/凸起/随机起伏各10%。
不需要再复制一套 SCUT 环境。landing 之后从低台阶/小起伏推进，并回归 flat。

按2026-11-12用户要求，P2直接在现有 `p2-spin` 混合50%平地、30%随机小起伏、20%缓坡，不新增rough阶段。
起伏0–3cm沿用SCUT，坡角±0.1rad为本项目设计值，坡面出生；9×9m地块、8行10列。
固定低难度混合，从第一轮同时训练；生成器按行分布几何难度，但不按训练表现或位移晋升。
不复用P1“走出地块一半升级”：原地旋转成功时位移接近零，不应该降级。
扫描只进入critic（81→158维）和局部地面高度；台阶信号/抬高腿指令/进度/卡住奖励已按P1任务隔离。
Actor 35维不变，不改部署合同，旧P2只能提取Actor初始化。评测JSON按出生地块报告，不保证全程不跨地块。
没有做困难地形或完整SCUT地形集复刻；若后续证明需要难度课程，再按旋转/平移成功率设计。

## 落地轮速奖励的实际差别

本项目 `isaac/wheelleg_tasks/env.py:639-659`：

- 零扭矩奖励：`20 * exp(-sum(tau_wheel**2)/1.5)`，在整个 airborne 阶段生效。
- 轮速惩罚：`-10 * sum((radius*wheel_speed - base_vx)**2)`，也在整个 airborne 阶段生效。

SCUT `state_machines/airborne.py:588-630,1129-1146` 和 `V14/env_cfg.py:1407-1457`：

- 指令 vx 和实际 vx 同号、且两者绝对值均>1 m/s，才启用方向奖励。
- 对两轮各算 `clip(sign(vx)*omega/10,0,1)`，取最小值；这是 rad/s 下的方向/最低速度要求，不是地速精确匹配。
- +10 正奖励与 -10 不足惩罚使用不同的接触计时窗口；不足惩罚要求触地计时已启动。
- 零扭矩奖励为 `20 * exp(-(max(abs(tau_wheel))/1.5)**2)`，受触地窗口限制。

我们的方法单位清楚、正反低速全覆盖，若近地时速度匹配准确有利于减少切向冲击；
但全程要求追踪 base_vx，与零扭矩奖励存在竞争，且未考虑腿相对运动、转弯左右轮差异、坡面接触切线。
SCUT 的窗口和饱和奖励更容易学到“空中少用力、触地前方向别反”，但不罚超速，低速/原地/指令与惯性方向
相反时不约束；达到10 rad/s不表示与地面无滑移。不能仅凭来源认定哪一个稳定性更好。

对初次训练稳定落地，优先采用 SCUT 的分时窗原则和有界奖励，先不强迫整个腾空期精确匹配地速；
再按实际触地前轮缘滑移、俯仰峰值、轮接触冲量和恢复时间判断是否加温和的近地速度误差项。
更准确的目标应基于每侧轮心接触切向速度，并单独处理低速/倒车，而不是无限加大当前 -10。
本次只分析，没有更改任何落地奖励或训练参数。
