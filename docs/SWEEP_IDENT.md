# 扫频与辨识指南（2026-11-21 修订）

这里保留上大无云台底盘正式训练前所需的扫频、辨识和配置交接顺序。

- **来源标注：** 历史参考为《轮腿RL_推进指南_v2》和《轮腿RL_执行手册》；上大当前训练口径以[阶段定案](上大轮腿训练方案/P1_DECISIONS_RUNTIME_20261121.md)为准；**[判]** 是本文补充的设计判断，**没有经过实测**，其中的姿态数、幅度、增益都只是起点。
- **分工：** 采集固件、原始数据和拟合脚本在 `D:/Code-RM/github` 的 `wheelleg_RL` 分支；本仓库只导入审核后的参数（见 §8）。
- **当前状态：** 本文不是测量报告。轮电机本次只允许轮子离地、无外加负载；不能测的量见 §6。未获得证据的字段不因完成空转而标为已辨识。

## 1. 先弄清三件事

### 1.1 策略输出什么，固件里跑什么环
| 通道 | 策略输出 | 固件里的闭环（500 Hz，H7 上算） |
|---|---|---|
| 4 个髋电机 | 位置目标 `q_ref = q_default + 0.5·a`，再按限位裁剪 | `τ = Kp·(q_ref − q) − Kd·q̇`，MIT 模式只发力矩（帧里 kp = kd = 0） |
| 2 个轮电机 | 速度目标 `ω_ref = 10·a`，再按上限裁剪 | `τ = Kd_w·(ω_ref − ω)`，换算成电流发给 C620 |

- 每个电机只有这一层 PD，没有积分，不串级。队内框架原有的角度环、速度环 PID 不用。
- 这层 PD 和训练里的 `motor_torque()`（`shu_train/wheelleg/tensor_ops.py`）是同一个公式。辨识时也用它，回放时才能一一对应。

### 1.2 Kp/Kd 不是辨识出来的
- 辨识的对象是 armature、摩擦、阻尼、力矩缩放、延迟、弹簧曲线，这些不随 Kp/Kd 变化。
- Kp/Kd 是自己选的控制器参数：先用一组临时增益做辨识，把参数写回模型后在仿真里选训练用的增益，再回实车复核一次，然后冻结（见 §7）。

### 1.3 为什么髋电机要在多个姿态做
一条腿的两个髋电机通过五连杆驱动同一个轮心，连杆惯量、被动铰摩擦、重力、弹簧力都经过随姿态变化的雅可比折算到电机上。
- 电机自身的摩擦和转子惯量不随姿态变；
- 被动铰摩擦和连杆惯量折算到电机上的量随姿态变。

只在一个姿态做，很难区分两类贡献，换个腿高就不准。所以必须带整条腿、在多个姿态做（华南虎的结论：大部分 gap 来自并联耦合）。

## 3. 髋电机力矩读数标定（手册 §3.8）

8009P 的力矩反馈由电流估算，可能有几个百分点到 10% 的误差，弹簧辨识要用这个读数，所以先标定。

以下挂载只用于**髋电机**：轮电机不通电驱动、不以锁轮产生反力。弹簧安全卸力并拆下，机架可靠固定。以关节输出端为准，先统一正转、力矩、长度和雅可比的方向与单位。

1. 每个姿态成对采集空挂和挂已知质量两次读数，从同一方向接近，按**实测角度**配对；记录温度、质量、悬挂点和稳态平均值。再反向接近重复，观察静摩擦造成的差别。
2. 若 `v挂点 = J(q)·q̇`，新增竖直载荷为 `F载`（朝下），理想平衡所需的**电机力矩增量**为 `Δτ理论 = −J(q)ᵀF载`。实测增量为 `Δτ读数 = τ读数,挂载 − τ读数,空挂`。腿自重在同姿态两次读数相减时近似抵消，不再从理论增量扣一次。
3. 每路在多个有效姿态拟合 `Δτ理论 ≈ k·Δτ读数`；理论增量接近零的姿态不用来除比值。报告写明 `τ校正 = k·τ读数 + b`，保留原始量和校正量。差分只能定比例，零偏 b 需独立参考；未测不能默认为已知。此式校正**反馈读数**，不是同时修改下发力矩和模型的指令。

**完成标准：** 对理论力矩增量足够大的姿态，检查同一路比例的一致性；旧手册以 4 个有效姿态间差异 < 5% 为检查线，不据此估计零偏或给轮电机签核。超出时先查几何参数和绳子是否竖直。

## 4. 髋电机扫频（手册 §3.9）

### 4.1 准备
- 车架空，机身固定，轮子离地，不装弹簧。
- 辨识固件用 §1.1 的 PD，在 H7 上 500 Hz 计算。每次运行把所用的 Kp/Kd 写进日志。
- 辨识模式单独设力矩上限，低于正常限幅；幅度从小到大加。通电前按手册 §3.0 检查。

### 4.2 工作点 [判]
腿长取短、中、长 3 档，腿摆角取 2–3 档，共 6–9 个中心姿态。离机械限位和奇异位形留余量。

### 4.3 每个工作点的三种激励 [判]
| 激励 | 做法 | 作用 |
|---|---|---|
| 同腿两电机同相 | 两个电机加同号的偏移 | 和反相一起，分别激励腿长方向和摆腿方向 |
| 同腿两电机反相 | 两个电机加反号的偏移 | 同上；哪种对应腿长取决于正方向定义 |
| 单电机 | 一个电机动，另一个用 PD 保持 | 直接看出两个电机之间的耦合 |

手册写的是“两条腿同相、反相”。机身固定时左右腿在力学上基本独立，信息量更大的是同一条腿两个电机的同相和反相 [判]。左右腿同相、反相成本很低，照手册也做一遍，同时能暴露机架刚度和供电压降的问题。

### 4.4 每种激励的轨迹
| 轨迹 | 参数（起点 [判]） | 主要用来定 |
|---|---|---|
| 静止起动 | 同一姿态下，从匹配的保持力矩开始，向正、反方向缓慢增加输出；以编码器噪声以上的持续运动判起动，记录阈值与重复范围 | 扣除静态负载后，估计起动静摩擦力矩；与换向尖峰、运动摩擦分开 |
| 慢速三角波往返 | 0.2 / 0.5 / 1 rad/s | 摩擦（同一位置正反方向力矩差的一半）、重力（均值）、粘滞阻尼（随速度的变化） |
| 正弦扫频 | 0.5 → 5 Hz，每段 20–30 s；幅度 ±0.05 rad 起，再到 ±0.1、±0.2 rad | armature、延迟 |
| 阶跃 | 0.1 / 0.2 / 0.3 rad | 超调、力矩饱和 |

用 2–3 组不同增益各跑一遍（例如 Kp 15 / 30 / 60 [判]），范围要覆盖打算在训练里用的值。
- 髋电机从低增益开始，例如 Kp 10–15、Kd 0.5–1（星云的量级），确认不振荡后再往上加。
- 低 Kp 时腿到不了目标位置没关系，拟合用的是实际关节角。
- 比较几组增益下拟合结果及重复测量的不确定度；若差异超过重复性，先查未建模效应、饱和或记录时延。

### 4.5 记录
500 Hz：指令与反馈各自的时间戳、位置/速度指令、实测关节角和速度、限幅前后下发力矩、原始反馈力矩/电流与校正值、温度。每次运行另记 Kp/Kd、工作点、激励类型、母线电压 [判]。

### 4.6 拟合顺序 [判]
不要一次搜索全部参数，否则参数之间会互相补偿。
1. **静态：** 各工作点的保持力矩和仿真对比，检查质量、质心、几何。对不上就改模型，不要拿摩擦去凑。
2. **静止和匀速分开：** 起动阈值给静摩擦。另在同姿态、相同速度幅值、相近温度下，取正反向匀速维持力矩差的一半，拟合 `τ差半 ≈ τ库仑 + c·|q̇|`；剔除加减速、换向、饱和段。记录方向不对称及跨姿态残差，不能只凭一条曲线反推出各被动铰链摩擦。
3. **扫频和阶跃：** 使用 §3 已校正的力矩，估计等效 armature 与延迟；先用时间戳约束延迟，不用任意调整力矩比例去补相位误差。
4. **合并：** 所有工作点、所有增益共用一组参数一起拟合；留一组不参与拟合的数据做验证。
5. **带弹簧验证：** 弹簧辨识完成后，冻结髋电机参数，带弹簧重跑一部分扫频。实车是带弹簧的，最终以这一遍为准。

### 4.7 验证与记录
采集前按完整工况划分拟合和留出数据，并约定误差指标和容差。先用**关闭随机化的标称模型**回放未参与拟合的姿态或轨迹，报告正反起动力矩差、关节角/速度跟踪误差、力矩残差、扫频幅值比和相位差。误差若随姿态、温度或方向系统变化，先查五连杆几何、负载、滤波/延迟和弹簧滞回，不将同一损耗既计为主动关节摩擦又计为被动关节阻尼。域随机化的覆盖验证另见 §8。

## 5. 气弹簧（指南 §4 第 5 条，手册 §3.11）

气弹簧不扫频，用准静态网格加匀速往返。

**原理：** 静止时 `τ_电机 = τ_重力(q) + τ_弹簧(q) + τ_摩擦`，其中 `τ_弹簧 = J_s(q)ᵀ·F_s`，`J_s = ∂L/∂q`，L 是由五连杆几何算出的弹簧长度。每个姿态有 2 个电机方程、1 个未知量 F_s，多出来的方程用来检验几何。

1. **无弹簧网格（基线）：** 每条腿在两个电机的工作范围内取约 10×10 个姿态，每个姿态停 1–2 s，取静止后的平均力矩。每个姿态从两个方向各到达一次，用来分离摩擦。
2. **装弹簧再扫：** 按实际关节角、接近方向、温度和同一套增益与无弹簧数据配对，不只对齐命令值。
3. **相减：** 两次校正力矩之差先称作“装弹簧后的附加保持力矩”。修正装拆改变的自重，检查零偏漂移；按约定的轴向力符号用弹簧雅可比对两髋力矩联合拟合，排除力臂近零的姿态，保留残差。
4. **拟合：** `F_s = F0 + k·压缩量`。两方向均值估计标称静态力；扣除关节方向性误差后，以两方向半差估计等效滞回，不把全部方向差直接归因于弹簧。
5. **阻尼：** 0.2 / 0.5 / 1 rad/s 匀速往返，减去静态部分后对 `L̇` 拟合，得到 c。
6. **热机复测：** 车运转、电机温度稳定后再测一遍，两次的差值用来检查随机化范围。
7. **左右弹簧分开辨识。**
8. **整车复核：** 落地，在 3 个腿高下静止站立，电机力矩和仿真的差 < 10%。

**完成标准（手册 §8.2）：** 10×10 网格有弹簧、无弹簧各一遍且两个方向；不同速度拟合出阻尼；左右分开；热机前后各一次；两个电机算出的 F_s 一致。两个电机不一致或残差大时，先查弹簧安装点坐标和 L(q)。

**注意 [判]：**
- 拆掉弹簧时弹簧本体的重量也不在基线里，相减后会混进 `Δτ`，按 CAD 质量及安装位置估计其贡献，不预设可忽略。
- 带弹簧停在某些姿态时，保持力矩可能接近 8009P 的额定 20 Nm。缩短停留时间，盯着温度。
- 在弹簧接近自由长度的姿态安装，避免带预压装配。
- 网格要覆盖弹簧的全部行程（75 mm），接近行程两端时放慢。

## 6. 轮电机：仅离地空载（上大台架约束）

本节所有采集和留出验证均使用实际车轮、轮子离地自由转动；**不安排堵转、制动加载、挂载或落地驱动试验**。§3 的已知载荷标定属于髋电机，不是轮电机的前置能力。确认机械固定、防护、限速、限流、温度与急停后，从低速开始；各轮分别记录电压、电流/反馈、轮端速度、指令、温度和时间戳。

| 空载试验 | 交付结果 | 解释限制 |
|---|---|---|
| 正反向缓升电流至持续起转 | 起动电流及重复区间 | 若没有可信的轮端转矩/电流系数，保留 A，不换算成“实测 N·m”。 |
| 正反多档匀速、空载速度阶跃 | 稳态电流–轮速曲线，速度环响应、延迟和该电压/限流下已达到的速度 | 有可靠力矩换算后，可估空载轴端等效库仑摩擦与黏性阻尼；最高**已测**速度不自动等于空载极限。 |
| 滑行和空载加速 | 衰减和加速曲线，检查等效惯量与损耗组合 | 先记录驱动器是滑行、零电流控制还是电制动；不能把电制动当机械摩擦。没有独立惯量或力矩尺度时，单靠滑行不能分别定出惯量和绝对摩擦。 |

留出另一组转速、方向或温度，在相同空载条件验证。报告分清 **实测**、**基于已知量的估计**、**空载不可辨识**：带载传动效率、最大可用轮端力矩、完整扭矩–转速包络、轮胎对地静/动摩擦及滚阻不由本节签核。也不拿资料额定值、仿真随机化范围或空载加速结果冒充实测。只签空载子项；整项 `wheel_torque_calibration_and_envelope` 保持待确认，不能填“完成”绕过训练就绪检查。

**换轮之后：** 更新轮径、质量和轮侧惯量，重做左右轮空载对照及独立留出回放。若只换轮胎材质，本台架不能证明新的接触摩擦落在原训练范围内；注明适用边界即可，不增设带载任务。

## 7. 用辨识模型选 Kp/Kd，再验证冻结 [判]

**增益由控制设计给出，辨识提供选它的依据。** 先用保守的临时增益采数据；辨识出惯量、摩擦、弹簧、延迟和执行器能力后，按所需跟踪带宽、超调、噪声与力矩裕量选候选增益，不存在由一组扫频数据唯一决定的“正确 Kp/Kd”。

- **四髋位置环：** 在单姿态近似 `J_eff·q̈ + b_eff·q̇ = τ`、忽略弹性和延迟、采用 §1.1 的位置 PD 时，给定目标自然频率 ω_n（rad/s）与阻尼比 ζ，可用 `Kp ≈ J_eff·ω_n²`、`Kd ≈ 2ζJ_eff·ω_n − b_eff` 生成候选。这不是带气弹簧五连杆的精确整定式；若局部弹性不可忽略、计算结果不合理或存在饱和，要在已辨识的多姿态模型里重选。用独立的起停、跟踪轨迹和带弹簧阶跃比较响应、力矩峰值/饱和占比、振荡与噪声，回到台架复核后冻结。
- **两轮速度环：** 代码中轮位置误差置零，只有 `τ = Kd_w·(ω_ref − ω)`。名字叫 Kd，但对**速度误差是比例增益**；不能套四髋的位置环公式。按 §6 空载数据选保守候选，只签“空载已验证”。车体负载下的带宽、力矩裕量仍是模型预测，不因选出了 Kd_w 就变成实测。
- **是否分策略：** P1 的 flat、landing、混合阶段优先用同一套标称增益。P3 跳跃先以 P1 的标称增益作为对照，不要求第二套，更不因跳跃就默认调硬。若 P3 在同一套下持续出现可归因于增益的不足（蹬伸跟踪跟不上且力矩有余量，或落地振荡过大），再单变量比较 P3 专用腿部增益；若一直顶到力矩上限，先查执行器包络和动作目标。每份策略按其训练时使用的增益部署；如确有两套，验证切换前后目标与输出力矩不跳变。此为建议，不代替负责人确认 P3。
- 参考值只解释选择空间：华南虎发布 flat 的主动腿 60/2；复旦非腿熊 plane 源配置为 20/1，其 Jump 快照为 6/0.5，两者轮通道均 0/0.2。不同车与控制实现不能照搬；出处见 §9。

P1 当前 Kp/Kd 与输出的训练倍率均为 ×0.9–1.1，这是训练不确定性，不是辨识算法，也不是实车可随意改增益的许可。更改标称值后应按新闭环回放和复核；是否续训看实际退化，不按某个倍率自动判定。

## 8. 结果写到哪里

原始数据和拟合报告留在固件仓库；审核后的参数导入本仓库。字段按逻辑关节顺序 `left_front, left_rear, left_wheel, right_front, right_rear, right_wheel`。

| 辨识结果 | 字段 |
|---|---|
| armature | `robot.yaml: training.joint_armature` |
| 起动静摩擦 | `training.joint_coulomb_friction`：本项目接到 PhysX static friction；旋转关节单位 N·m |
| 运动库仑摩擦 | `training.joint_dynamic_friction`：运动中的常值阻力矩幅值，N·m |
| 黏性阻尼 | `training.joint_viscous_friction`：速度比例系数，N·m·s/rad |
| 转速–扭矩包络 | `training.saturation_torque_nm`、`no_load_speed_rad_s`、`wheel_speed_limit_rad_s` |
| 弹簧（左右各一个值） | `training.spring.reference_q_m`、`direction`、`f0_n`、`stiffness_n_m`、`damping_n_s_m`、`hysteresis_n`、`force_limit_n` |
| P1 延迟 | 仍实测传感采样→策略取数、策略发令→执行两段。训练额外观测延迟为 0；`training.control_randomization.action_delay_steps=[0,5]`（每步 2 ms，即 0–10 ms）；评测 `training.evaluation.action_delay_steps` 固定取实测值。均指 P1 策略配置，不套用 P2/P3。 |
| Kp、Kd、力矩限幅 | `policy_meta.yaml: kp`、`kd`、`torque_limit_nm`（轮通道的 `kd` 就是 `Kd_w`，`kp` 不参与计算） |
| 完成标记 | `robot.yaml: pending_measurements` 下的 `hip_torque_calibration_and_envelope`、`wheel_torque_calibration_and_envelope`、`motor_sweep_and_held_out_validation`、`spring_left_*`、`spring_right_*`、`measured_sensor_and_action_delay` |

- 弹簧模型见 `shu_train/wheelleg/tensor_ops.py` 的 `spring_force()`：`压缩量 = clamp(direction·(q − reference_q_m), 0, 行程)`，`F = f0_n + stiffness_n_m·压缩量`，再加阻尼项和 `hysteresis_n·sign(q̇)`。`hysteresis_n` 填两个方向之差的一半。
- **第一关：标称验证。** 左右分别拟合并冻结参数；关闭域随机化，在事先留出的完整工况上按 §4.7 核对。带弹簧验证只适用于髋腿，轮始终只做空载留出。若标称不过，回查坐标、力矩标定、时延及重复计入的损耗。
- **第二关：覆盖验证。** 用左右、冷热机和重复测量的差别检查训练范围，报告哪些工况未覆盖；随机仿真包络覆盖实测，不等于标称模型正确。当前关节摩擦是“标称值＋正向增量”，不是以辨识值为中心抽样。实测后先算出实际训练上下界是否包含标称，再决定是否另行修改随机化；本手册不改已定幅值或采样时机。
- **弹簧交接。** 左、右分别提交标称力曲线、滞回、阻尼及其残差；P1 每回合每根弹簧的 `±30 N` 是基准力随机偏置，不是拟合容差或新的力矩上限。已取消 P1 随机功率降额/空载转速下降，不等于取消电机真实力矩和转速限制。
- 报告同时标明部件/侧别、输出端坐标和单位、温度和负载范围、原始数据与拟合版本、留出指标，以及未测项。证据不足就保持待确认，不用其他队伍的测值填空。

## 9. 待确认

- **跨仿真器的一致性：** Isaac Sim 5.1 的旋转关节三种摩擦量按 §8 交付。MuJoCo 的 `frictionloss`、`damping` 不能自动复现独立的起动/运动摩擦；用同一留出轨迹比较起动、匀速和换向，不靠改字段名认定对齐。
- **力矩缩放归属：** 固件与拟合报告要注明反馈修正和指令换算分别由哪一层执行，保证不重复乘除。P1 输出随机倍率不是标称反馈校准系数。
- **`pending_measurements` 填什么：** 代码只判断是否为 `null`，没有规定填报告路径、日期还是别的。
- **髋电机的空载转速：** 带着腿、受关节行程限制，很难直接测。是用手册的 17.6 rad/s@24 V，还是用大幅阶跃里的速度饱和段来估，需要定。
- **采集格式：** 遥测协议文档还没有；手册里的文件名是 `hip_sweep_<日期>.csv`、`spring_with_<日期>.csv`、`spring_without_<日期>.csv`。
