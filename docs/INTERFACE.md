# 策略与固件接口

**部署输入是两路，不是单帧 35 维直接出动作。** P1、P2、P3 各自保存一套 encoder 和 Actor，不共享权重。物理／PD 为 500 Hz，策略为 100 Hz。

| 接口 | 合同 |
|---|---|
| 当前帧 `obs` | obs_version 3，单帧沿用 35 维布局：指令(3)、站高指令(1)、机体角速度(3)、机体系单位重力(3)、相对关节角(6)、关节速度(6)、上一原始动作(6)、模式(7)。 |
| `obs_history` | 5 帧相同处理后的 `obs`，从旧到新展平为 175 维，末帧即当前帧。每个策略步更新一次；复位或切换策略用首帧填满，不混入上一策略历史。落地首触和同策略内交回驾驶不是复位。 |
| 速度 encoder | `175 → 128 → 64 → 3`，只估计机体系三轴线速度（m/s），无接触预测头。 |
| Actor | 当前帧与估计速度拼成 38 维，`38 → 128 → 64 → 32 → 6`；隐藏层 ELU。每套含偏置 46,505 个参数，不含 critic。critic 的特权输入不进固件。 |

六通道依次为 `left_front, left_rear, left_wheel, right_front, right_rear, right_wheel`，不是 USD 或 CAN 的自然顺序。机体 x 前、y 左、z 上；直立重力为 `[0,0,-1]`。腿角减默认角（rad），轮位置输入恒零，关节速度用 rad/s。各物理分量**先限幅、再缩放、最后清理非有限值**；上一原始动作首次置零，作为观测时限在 ±100。

输出按同一顺序映射为四腿位置残差、两轮速度目标。`action_clip: null` **仅表示不裁剪原始动作**；不取消腿关节和轮速目标限幅。缺失的默认角、方向、限位或辨识值不能解释成零。`tools.gen_c_config --interface-only` 只导出接口（`WL_DEPLOYMENT_CONFIG_READY=0`）；完整导出须通过缺参检查。固件与训练必须使用同一缩放、模式语义和历史帧顺序。
