# P1 混训八项奖励定案（2026-11-20）

对象是从台阶中央出生、关闭 heading、可斜向与倒车下阶的 P1，并非旧 SCUT 参考车的世界 +X 直线走廊。以下 1–8 项均已批准。不改变独立 flat、被动 landing、P2/P3、Actor 输入及课程。数据仅来自两份可复核的冻结配置：

- [华南虎 `rough_rotation_stair/2026-07-30_09-16-27` 参数](../../../wheeled-legged_RL/pretrained/26_infantry/rough_rotation_stair/2026-07-30_09-16-27/params/env.yaml#L1925)，[计算与 dt](../../../wheeled-legged_RL/source/agent_tasks/agent_tasks/direct/wheelbipe/wheelbipe25_v3/env.py#L3709)。不引用轻量 flat 的高度门控来代表本次运行。
- [复旦非腿熊 Upstairs v2 激活项](../../../fudan_rl_wheel_leg/plane/logs/wheel_legged/上台阶3_angz+添加随机地形，进一步训练v2/legged_robot_config.py#L185)、[具体函数](../../../fudan_rl_wheel_leg/plane/logs/wheel_legged/上台阶3_angz+添加随机地形，进一步训练v2/legged_robot.py#L1804)、[任务接触名单](../../../fudan_rl_wheel_leg/plane/logs/wheel_legged/上台阶3_angz+添加随机地形，进一步训练v2/wheel_legged_config.py#L80)。`enhance` 有些是负值；不能把 `plane` 基础版本的参数当本次快照。
- [现有上大连续项](../../wheelleg/shu_rewards.py)、[地面测量与旧路线项](../../isaac/wheelleg_tasks/env.py)、[课程和到达判据](../../wheelleg/shu_terrain.py)。下表普通项按带符号每秒系数讨论，非轮接触最低 −2/s，普通项逐项 ±1/s 后乘 0.01 s；事件独立。两校表内为名义系数，不是直接可加的每拍分。

**验证分账。** 自由（平地/粗糙/井字/坡）不发穿越成绩；前进上、前进下、倒车下分别统计外围承重成功、跌倒、卡住。再分直入/斜入和普通/带沿，不让容易的前进样本掩盖倒车失败。课程严格沿用已定复旦式规则，诊断不回流 Actor 或代替验收。切入混训首版与“只续训 flat”在同指令的平地保留集对比，检查平地能力是否退化。

**按什么切换。** 物理奖惩按车体当前 XY 所在图块（含普通/带沿金字塔），不是按出生标签。驶进邻块下一拍采用邻块口径；整图外圈平坦边带用平地口径，不添加小地块边界终止。路线指令、完成与课程仍属于本回合分配的任务。诊断不回流策略。

**日志口径。** `Mixed/{forward_up,forward_down,reverse_down}/{plain,lip}/{straight,oblique}` 按回合出生标签分组，每个 rollout 汇总已结算样本；无样本不虚报零成功率。卡住看连续 1 s 内，位移沿“出生航向 × 已执行纵速指令的符号”的投影是否小于 0.05 m；不把路径长度或世界 X 当作有效位移。路线完成后不再累计卡住或力冲量；后续行驶若摔倒，可能同一回合既完成过路线又摔倒。两主轮分别记录 `max(Fz,0)` 峰值和随 2 ms 物理拍的积分：**积分包含承重，不是某一次碰撞的冲量**。另记非主轮/导轮接触；现有传感不能判断接触点一定在凸沿。站高原始误差和扫描参考面在 `extras["p1_mixed"]`，不作为策略输入；分越阶阶段的饱和率与平地保留集是待训练分析，不是已有训练结果。

**平地 `−100` 的来历。** 沿用复旦非腿熊 `plane` 的合成姿态项及逐项裁剪，不是华南虎的参数，也不是上大实车寻优结果。见[当时的平地设计记录](P1_FLAT_REWARD_DESIGN_20261115.md#L53)及[复旦 plane 配置](../../../fudan_rl_wheel_leg/plane/wheel_legged_gym/envs/base/legged_robot_config.py#L195)。直立附近若车体相对竖直线倾斜 θ，`gx²+gy²=sin²θ`：3° 时平地罚约 0.274/s，5.74° 左右到 1/s 上限；非平地 `−20` 到约 12.92° 才封顶。两者封顶后均为 −0.01/策略拍（100 Hz），不是 5.74° 内不罚。
