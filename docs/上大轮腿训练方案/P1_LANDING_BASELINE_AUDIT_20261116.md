# P1 被动落地｜三方核对与上大候选方案

2026-11-16。**以下是第一轮核对的历史底稿，候选不是决策；后续答复以[被动落地设计记录](P1_LANDING_DESIGN_20261116.md)为准。** 目标是已经会平地行驶的 P1 在意外离地后如何接住自己，不训练按键起跳、越梁、完全翻倒复位；主动跳属于 P3。已定顺序是平地基础→平面被动落地→混合地形。下文将历史已训数据、当前源码和新车建议分开。数字仅作参考车复现初值，不填写上大真车缺参。

## 1. 上大现行参考车：从出生到恢复

| 环节 | 目前真正执行的逻辑 | 对上大新车的建议（待确认） |
|---|---|---|
| 地形／初态 | 平面训练，名义 60% 普通地面出生、40% 空中出生；后者才打开首次落地事件。当前常规模板无状态库替换时适用。一回合最多一次，后续主动蹦跳不能重新领落地奖。以按腿姿算出的安全出生根高为基准**再加高度偏移**，不是把根直接放在 0.42 m，也不是每条腿从同一轮底净空开始落。 | 第一版保留平面与 60/40 作对照；正常地面样本用已确定的 P1 地面配方维持行驶能力。真实从台阶驶出放到混训做迁移测试，不在此阶段同时调地形与落地奖励。 |
| 速度与姿态 | 空中出生初始世界竖直速度为 0，由重力自然下落。前速 80% 随指令加高斯噪声 σ=0.3 m/s 并限幅，20% 在 ±2.5 m/s 独立采；侧速 ±0.5 m/s；初始 roll/pitch 分别 ±0.1/±0.2 rad，三轴角速度上限分别为 0.05/0.1/0.5 rad/s；参考腿长 0.15–0.35 m、摆角 ±π/4。空中指令限前速 ±2.5 m/s、偏航 ±π/2 rad/s；首次触地后 3 s 观察窗内通常不重采样，提前结算不提前解冻，外生时间截断／无接触等另处理。 | 训练用原本的 80/20 优于全部让地速等于指令；分开报告“指令=0 但仍在滑”“正反向带速”和原地落下。五帧 encoder 不是测距仪，空中冷启动的重复历史也不会凭空给出真实水平速度。地速可作监督／打分，不作 Actor 真值输入；后续用从地面真正驶出的连续历史单独验收。 |
| 腾空 | 三项均只罚不奖，达标为零：轮心在**仅含 yaw 的坐标系**下接近机身下方（−4/s 上限），两轮轮缘速度接近机身真实水平前速（−6/s 上限），两腿分别计算低于 0.28 m 的缺口再取均值（尺度 0.1 m，最多 −3/s）。三项到首次接触即关。轮心居中不是平地的“两轮相对错位”；轮速目标也是无滑移近似，不是接触点准确切向速度。 | 保留三项的功能和符号，不给延长滞空发奖金；伸腿是给着地留压缩行程，不是“越长越好”。0.28 m 不直接移植，待本车 CAD／气弹簧和缓冲行程确认；如出现提前伸直顶死，先看压缩行程和冲击，不贸然加大引导。 |
| 触地与缓冲 | 2 ms 的当前接触采样；实现取接触力向量的模。任一刚体 >3 N 记首次触地；双主轮各 >20 N、无非轮接触的连续支撑满 0.1 s，或首次触地后到 0.5 s，先到者结束缓冲。弹跳不延长窗口。现行腾空、缓冲期暂停速度／高度跟踪、竖直速度、站定与指定加速度项；俯仰负罚在缓冲恢复。此次对 flat 的改法尚未自动应用到 landing。 | 腾空不罚自然下落速度，不要求电机追地面高度；触地缓冲不罚合理的屈腿减震。恢复双轮支撑后回到新 flat 的跟踪与姿态逻辑，不保留旧 flat 的水平姿态正奖。正常地面与事件引导的裁剪分开：例如把 −4/−6/−3 的有界引导再统一裁至 −1/s，会改变三者相对强度。推荐先按各自已有边界，事件结算不乘 dt。 |
| 导轮与碰撞 | 事件仍开启时：机身／腿连杆等非轮非导轮触地判事件失败。新导轮接触用**触前一个物理采样**的自身下落速度判级：≥1.0 m/s（或首采样即接触而无前值）判硬碰；较轻接触扣 `0.5×速度/1.0`，可继续恢复。同一采样多个导轮取最快的，只扣一次；支撑在导轮上不能计作双轮稳定，长时支撑仍可能物理终止。旧参考车在指令冻结窗口内另有连续非期望接触 `−4×8=−32/s`。事件一旦首次成功即关闭，不能假设其硬碰标记此后还在整窗监视。 | 轻擦可恢复、机身／连杆或硬导轮碰撞不可算成功；“全程不碰非轮件”另报质量指标。若判 3 s 窗末成功，需要让硬碰与失稳监测覆盖结算后的剩余窗口。**勿把新 flat 的 −2/s 和旧 landing 的 ×8 默认为同一决定**；是否额外罚持续借力、罚多重依据触地占空比和硬件辨识再议。 |

## 2. 我们已经训到什么，哪些不能据此推断

11 月 13 日训练快照 `current` 第 4883–5082 轮、指令档 0.70、偏移上限 0.42 m：首次恢复率 **82.93%**，3 s 窗末无非轮接触且稳定 **40.44%**，诊断不稳定 **49.45%**。同一档刚进入后的 200 轮三个指标为 84.17%、45.74%、40.85%。这说明只盯首次恢复会漏问题；分母、容许导轮接触规则和观察窗口不同，**不能把 82.93−40.44 当成恢复后又摔的概率**。新方案应对同一批事件同时记“曾稳／末稳／仅轻擦／硬碰／提前截止”。不同 run、不同高度和探索噪声不作因果消融。

另有无观测噪声、固定延迟的 `model_8400` MuJoCo 报告，16 个 drop/drop_leg 工况均标记 ok。这是少量固定条件下可以恢复的正面证据，不是 16 组大样本成功率，亦不能由简化模型验收上大导轮冲击或实机。交叉评测保留原地、前进、后退、左右倾斜、指令不匹配和无摔倒平地回归；使用同种子和同初始状态比较策略。冲击力峰值、压缩行程、触地前后速度与持续支撑分别记录；力峰值阈值和允许行程应由上大真车标定。
