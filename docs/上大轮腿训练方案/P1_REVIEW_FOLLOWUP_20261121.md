## 已确认范围

- P1：机身质量 ×0.9–1.3、指定腿和两主轮 ×0.9–1.1、机身 COM 的 x/y/z 分别 ±4/2/2 cm；额外惯量随机项 ×0.9–1.1。这里的“额外”沿用之前汇报的先随质量再施加独立倍率，并非将最终惯量裁回 CAD 的 ±10%。机身理论乘积 0.81–1.43，指定腿轮 0.81–1.21。真实刚体名、标称数值由本车核对；不靠“除机身之外全部刚体”猜名单。
- 主轮静摩擦 0.5–1.2、动摩擦 0.4–1.0；机身、导轮分别有自己的材质随机化；每次采样保证动摩擦 ≤ 静摩擦。后两组具体静/动范围和恢复系数还需负责人签；不能因为知道外校数值就替上大填上。以下建议不改地面材质、合成方式、关节轴内摩擦。训练域随机化范围与实车标称值分开。
- Flat 六桶都从 25% 起步，各桶按自己的进度退站高宽核（25、35、45、55、65、75、85、95、100%）。不是按训练轮数，不是所有桶共用一个均值；landing 和 mixed 接满档，不重开宽核。60–80% 公式和独立六桶晋级不重问。

## 运行时修复建议：以下尚未改

| 项目 | 处理建议及验收用例 |
|---|---|
| Flat 片段最后一拍 | 传现成的数值无效标志到命令结算器；无效时既非成功也非物理失败，单列中断、不进分母。仅普通时限与自然结束同拍可照常结；真实物理摔倒且样本有效仍算失败。按调用链测试这三例，而非只测 helper。没有理由为低概率重做课程。 |
| RISE/CATCH → DRIVE | 把**本次动作的计分**和**下一次动作的观测**分开。在动作下发时保存本拍执行指令；判稳当拍只结旧任务最后一拍进展及应有一次性事件，下一次给 Actor 的观测立即改为驾驶指令，直行立刻锁当时 yaw。下一次驾驶动作执行完才结普通驾驶站高/速度奖。不增等待、不清历史；AIR→首触的特殊开关仍按已定当拍生效，不用全局“所有阶段延迟一拍”。 |
| 空生无效出生 | 只对空生：在当前回合新 root/q 放置完、首个物理积分前，按本车碰撞几何与实际出生地面验证净空（主轮、导轮、机身、腿连杆等；不能只看根高或刚体原点）。用候选姿态和 FK 的净空预检，或能验证为当前姿态且不推进时间的重叠查询；不读上一回合力缓存，也不把首个 2 ms 真触地一律算无效。无效候选重抽同一已抽高度带，单列生成失败，不进 PPO/事件/晋级/20 s 时钟；有限次仍无可行姿态停止并报告姿态/高度带，而非默默降低档位。预设起身允许支撑，不用此空生规则。测试：重置前有接触但新姿态悬空、出生已穿地、出生悬空后一子步真实触地。 |
| 跨地形限速 | 按**当前地块**对最终下发指令限幅；仅 30% 独立平面整个回合绕过地图限制。台阶路线上原范围不变；前进出台后驶上坡，+2.5→+2.0，负速保留负号；坡上 yaw 绝对值 ≤π，台阶关闭 heading 不因跨块变成自由驾驶。离坡后恢复原采样目标，不重采、不重置、不改课程。训练桶、评估读最终指令而非未裁 target。 |
| 纵速口径 | P1 驾驶奖、flat 片段成绩、critic 的驾驶误差、评估误差都用水平航向轴投影 v_h = v_world,x cos(yaw) + v_world,y sin(yaw)，与本拍有符号 vx_cmd 比较；报告可取绝对误差。用爬坡、斜入、倒车、有世界竖速的合成轨迹对拍。**两个例外**：复旦式台阶升降行诊断继续用机体系 vx；encoder 继续监督机体系三轴速度。它们不是驾驶误差，不随本项改变。 |
| 退火时钟 | 建议 PPO 每段采样开始时对六个桶分别取进度快照 f[k]，算 w[k] = clamp((0.80−f[k])/0.20,0,1)。100 Hz×48 拍=0.48 s；这 48 拍按实际执行片段的桶取其固定 w[k]，站高正奖仍为 (T+wW)/(1+w)。桶在中途达标正常晋级、片段正常结算、新片段指令包络按已定课程更新；**只有宽核权重等下一批采样刷新**。一个环境期间换桶可用另一个桶的已冻结权重；不是所有 4096 环境同一个 w。断点恢复先载课程再取新快照；只记未加权 T、W、w、实际高度误差及裁剪比例，不重复加奖。例：65% 的桶 w=0.75；第 20 拍升至 75%，本批该桶仍用 0.75，下一批才用 0.25。满档后 w=0；e=0 永远 +1/s。总回报不保证单调。 |
