## 阶段边界与后续交接

- **训练顺序**：P1-flat 全部指令范围开放后再训被动落地。地面预设起身整合在落地阶段，不另训旧 recovery。落地阶段只升掉高，不重开驾驶课程。
- **读表顺序**：同一问题先看对应阶段的最新决定；基线、旧实验参数和早期候选不能覆盖定案。独立 flat 与落地专项对轮错位的计分并不相同。
- **上大模型到位时再确认**：出生腿姿与腿长可达域、连杆干涉和弹簧行程、残余轮速与关节初速、释放时间、整车净空和掉高分带边界、接触阈值及刚体名单。不要把华南虎参考数值直接当作上大实车参数。
- **选模与后续阶段**：负责人自行完成 sim2sim，指定进入混训的 checkpoint。混合地形、P2、P3 的待讨论项保留在总决策记录里，不属于本轮落地定案。
