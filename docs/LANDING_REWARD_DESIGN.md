# P1-landing 首次落地奖励设计

基于43906c6，独立分支codex/landing-reward-design。仅参考华南虎仿真设计；未上云训练、未实机验证。

## 第一版尺度

| 项 | 权重/总额 | 生效范围 |
|---|---:|---|
| 恢复进展 | 每次空中出生累计最多+0.75 | 首次触地后、无非轮碰撞、双轮持续支撑 |
| 窗口末稳定恢复 | 每事件一次+1.5，否则−1 | 首次接触后固定3s末连续稳定0.5s |
| 空中轮力矩使用 | −0.1/s，总额最多−0.1 | 出生后的首次未触地段，按额定轮力矩归一化 |
| 原终止 | −4/次 | 数值异常也保留，取消landing的腾空×6倍率 |
| 非轮触地 | 保留−4/s | 取消landing的腾空×25倍率；一次碰撞永久取消该事件正奖励资格 |

进展质量Q=exp(−0.25×sum((状态误差/尺度)^2))。
尺度为最大roll/pitch=10°、最大roll/pitch角速度=0.5rad/s、世界垂直速度=0.2m/s、高度误差=0.05m。
进展只支付Q相对历史最高值的增量，不对每帧“已经很好”重复发钱。总正奖励≤2.25，低于原失败终止代价4。
稳定恢复允许合理先后触地；诊断的50ms对称门槛保留，不用它强迫随机不对称初态同时触地。

## 取消相互冲突的原项

仅对p1-landing关闭旧+20/s空中零轮力矩奖励、+10/s轮心居中奖励和全程−10轮速精确匹配。
首轮不加入强制精确轮速项：Actor没有真实机身速度/高度观测，旧目标还忽略腿运动和左右轮差速。
保留原髋限位、姿态、能耗和平滑项。首次自由落体期间关闭速度跟踪、站定速度、高度、竖直速度、姿态正奖励及俯仰负罚；角速度与roll约束仍保留。
首次任何触地后恢复这些地面项，不给弹跳重新申请免罚窗口。
宽核高度奖励采用最新配置1.5，未加大。

## 防取巧边界

- 只有reset真正采样的air掩码开启事件；自主跳起、触地抖动、单轮接触不会开启新事件。
- 使用物理tick计时，不用PPO可随机初始化的episode_length_buf；重复读取同一tick不重复计数。
- 记录500Hz当前法向力，要求整个策略间隔双轮支撑；不靠历史峰值伪装持续接地。
- 非轮碰撞永久锁定，随后站起来不补发干净恢复奖励。
- 首次任意接触启动3s固定窗，弹跳不能延长；出生2s无接触结算失败。
- 姿态、角速度、垂直速度、高度都连续达标0.5s，且窗口末仍达标，才支付一次完成奖励。
- 数值异常保持有限−4终止代价，事件仍活动时另支付−1失败成本，不能靠NaN逃罚。
- 提前外生timeout不假记成功，也不额外处罚随机初始短回合；没有接触/稳定奖励重发。
- 开始接地后不压低瞬时力矩，避免把必要缓冲动作当错误；不依据未标定峰值宣称结构安全。

## 未解决的边界与上线顺序

奖励无法保证无漏洞。此版没有机械冲击上限、近地轮缘滑移反馈或实车安全认证。
诊断FirstLanding不依赖奖励状态，课程/Actor观测不改，P3和其他阶段不改。
训练配置需重新生成/显式补齐landing_reward，旧快照不能悄悄使用默认值。
先做目标Isaac环境的最小启动、若干空中出生回合及旧flat回归，再做短训A/B。
监控按事件结算数加权的clean_success、碰撞恢复、数值终止、力峰值、恢复时间、目标裁剪和每项事件奖励总额。
若首批长期全失败，先核查reset/接触/计时与可观测性，不直接增大权重。

## 已执行验证

CPU对抗序列测试：正常落地、碰撞后恢复、反复弹跳、无接触、提前死亡、NaN、外生timeout、地面出生、部分reset、重复tick及2/10/20ms步长。
验证总正奖励上限、失败净新增回报为负、事件只结算一次、不同步长总额一致。
这些是奖励状态机数值测试，不代表Isaac接触、GPU训练或真实机器人已经通过。
